# Getting help

| You need... | Go to |
| --- | --- |
| How to do something in Forumulate | [Guides](https://forumulate.com/guides) |
| API endpoints, parameters and responses | [API reference](https://forumulate.com/reference) |
| Your first API call, the SDK, CLI or MCP | [Developer quickstart](https://forumulate.com/guides/developer-quickstart) |
| A question for us or other users | [Community forum](https://forumulate.com/community) |
| To know whether something is down | [Status](https://forumulate.com/status) |
| A bug in the SDK, CLI, MCP server, extension SDK or a template | An issue in that repository |
| To report a vulnerability | [SECURITY.md](SECURITY.md). Report it privately, never in a public issue |

GitHub issues are for bugs and feature requests in the public tooling. Product questions
get a faster answer, and help the next person, on the
[community forum](https://forumulate.com/community).

When asking for help, include the package version, what you ran and the full error, but
never an access token.
